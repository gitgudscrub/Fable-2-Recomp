# Project Sparrow launcher design

`mockup.html` is the approved clickable mockup (open it in a browser from this
folder; it loads `../../assets/app-icon.png` and Google Fonts). It is the visual
reference for the WPF launcher:

- Whole window is a storybook night scene; centred emblem, "Project Sparrow"
  title and motto.
- Round gold seal is the main action; its text follows the launcher state
  (choose disc, copying, play, restart to update).
- Edition ribbon at the bottom: Original / Enhanced / Experimental, with a
  "Custom changes" marker once a setting is changed by hand.
- Settings and Help open a parchment page that turns in from the window's right
  edge, with bookmark tabs: Settings, Controls, Updates, Help.

Palette: dark forest greens with antique gold; parchment pages use dark ink and
deep green accents. Fonts: IM Fell English (display), Alegreya Sans (body).
Must stay visually distinct from other recomp launchers (no banner card +
preset cards + permanent sidebar layout).
